# gitrb format and protocol

## Project layout

```text
gitrb.json
.gitrb/
  index.json
  meta.json
src/
  Workspace/
    .gitrb-node.json
    Baseplate/
      .gitrb-node.json
      source.server.luau
```

Each directory containing `.gitrb-node.json` is an instance. The directory
name is only a filesystem-safe display name; the JSON file is authoritative
for the Roblox name, class, order, attributes, tags, and properties. Script
instances store source in one of:

```text
source.server.luau
source.client.luau
source.module.luau
```

The index contains only files generated by the exporter. On the next write,
only files listed in that index can be removed, so hand-written files outside
the generated set are left alone.

## Snapshot JSON

The bridge sends a snapshot like this:

```json
{
  "schemaVersion": 1,
  "project": "MyGame",
  "placeId": 123,
  "gameId": 456,
  "roots": [
    {
      "id": "game.Workspace#0",
      "name": "Workspace",
      "className": "Workspace",
      "parentPath": "game",
      "order": 0,
      "properties": {},
      "attributes": {},
      "tags": [],
      "children": []
    }
  ]
}
```

Typed values use an explicit `__type` member. For example:

```json
{
  "__type": "CFrame",
  "position": {"__type": "Vector3", "x": 0, "y": 4, "z": 0},
  "rotation": [1, 0, 0, 0, 1, 0, 0, 0, 1]
}
```

Object properties use `{"__type":"InstanceRef","path":"game.Workspace.Target"}`.

## HTTP endpoints

All endpoints are under `http://127.0.0.1:1648` by default. If a token is
configured, send it as `X-GitRB-Token` or `Authorization: Bearer TOKEN`.

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/v1/health` | Protocol, project, and current revision |
| GET | `/v1/status` | Revision plus Git branch/status |
| POST | `/v1/sync/push` | Push an inline snapshot |
| POST | `/v1/sync/push/start` | Begin a large snapshot upload |
| POST | `/v1/sync/push/chunk` | Append one upload chunk |
| GET | `/v1/sync/pull` | Return an inline or chunked snapshot |
| GET | `/v1/sync/pull/chunk` | Read one chunk of a large pull |
| POST | `/v1/git/commit` | Stage and commit the project |
| POST | `/v1/git/push` | Push an existing Git remote |

The plugin automatically switches to the chunk endpoints for large snapshots.
The server checks `baseRevision` before writing. A mismatch returns HTTP 409
with `code: "conflict"` and the current `serverRevision`.

## Native place and model conversion

`internal/format` uses the Go Roblox file codec to decode and encode real
`.rbxl` binary places and `.rbxm` binary models. `.rbxmx` XML models remain
supported for compatibility. The CLI intentionally treats unknown or unsafe
values as warnings instead of inventing property values.
Attributes and tags are fully represented in the Git snapshot; native Roblox
files may not carry all of those editor-side fields, depending on Roblox's
file format and the source file.
